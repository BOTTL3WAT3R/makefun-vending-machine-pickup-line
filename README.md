A tiny program that writes one pickup line — spoken by a vending machine to a passing human — to /output/entry.txt: "My coil spends all day making snacks fall for strangers. You've pressed B4 three times this week — careful, I'm starting to fall too."

## Run it

```sh
python3 main.py
```
